# הנפשות – יסודות האלגוריתמים והסיבוכיות

אתר עם הנפשות צעד-אחר-צעד לכל האלגוריתמים של הקורס יסודות האלגוריתמים והסיבוכיות (אוניברסיטת בן-גוריון).

**לאתר:** https://katzq-wq.github.io/algo-animations

- כל אלגוריתם רץ לפי הפסאודו-קוד מההרצאות, על הדוגמה מההרצאה או על קלט משלכם.
- כפתורים לווריאציות (למשל מיון מיזוג עם פיצול ל-3, ערימה עם d ילדים, Dijkstra עם ערימה).
- חיפוש בחומר: מוצא את ההנפשה ואת ההרצאה והשקף הרלוונטיים.

האתר הוא קובץ אחד (`index.html`) ורץ כולו בדפדפן, בלי שרת.
